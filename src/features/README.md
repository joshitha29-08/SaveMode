# Features

This folder organizes code by application feature.

Examples include:

- Authentication
- Onboarding
- Sources
- Transactions
- Tags

## Guidelines

- Keep related feature logic together.
- Reuse shared components from `src/components`.
- Use `src/data` for backend data access.
- Use `src/lib` for shared utilities.
- Keep feature code independent where practical.

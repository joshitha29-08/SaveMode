# App

This folder contains the application's Expo Router routes, screens and layouts.

## Responsibilities

- Authentication screens
- Onboarding screens
- Main application tabs
- Root navigation layout
- Route protection and redirects
- Theme preview screen

## Guidelines

- Follow the existing Expo Router file-based routing structure.
- Keep screen-specific logic close to its route.
- Reuse shared components from `src/components`.
- Use `AppText` for application text.
- Use theme tokens rather than hardcoded design values.
- Keep navigation behavior consistent across web and Android.

# Data Layer

This folder contains data access and backend integration code.

## Responsibilities

- Reading application data
- Writing application data
- Supabase client integration
- Data transformation and validation
- Reusable data access functions

## Guidelines

- Keep backend access separate from screen presentation.
- Use the approved Supabase client configuration.
- Never expose secret keys in client code.
- Handle loading, empty and error states.
- Follow the database schema and approved architecture.

# Supabase

This folder contains database-related scripts and configuration for SaveMode.

Expected responsibilities include:

- Database tables
- Row Level Security (RLS) policies
- Balance trigger
- Default tags
- Delete-account function

## Guidelines

- Follow the approved database schema.
- Apply appropriate RLS policies.
- Never store service-role credentials in client code.
- Review database changes before applying them.
- Keep schema changes and migrations documented.

Refer to the approved BRD and technical architecture before implementing database changes.
